# 문체 어댑터: webnovel (수동 시작점)
사용자 스킬 webnovel-prose-engineering V1.1을 규칙 형식으로 옮긴 것. 근거는 교정이 아니라 사용자가 직접 정한 규칙이라 '수동'으로 단다. 교정이 쌓이면 관문을 통과한 편집만 이 위에 쌓인다.

## R1 주어-서술어 거리 좁히기 [채택]
- 언제: 수식어가 주어와 서술어 사이에 끼어 문장이 길어질 때
- 하라: 주어를 쓰면 바로 서술어로 닫고, 부연은 다음 단문으로 붙인다
- 근거: 수동
- 예: 이 바위굴은, 어제 갓 잡아 올려 …, 손질하기가 까다롭습니다 → 이 바위굴은 손질이 까다롭습니다. 어제 갓 잡아 올려 짠내가 가시지 않았고…

## R2 '의·것·적' 걷어내기 [채택]
- 언제: 명사화·번역투가 속도를 늦출 때
- 하라: '-의', '-것', '-적'을 동사·부사로 푼다
- 근거: 수동
- 예: 중요한 것은 타이밍이라는 것이다 → 중요한 건 타이밍이다

## R3 피동 대신 능동 [채택]
- 언제: '-어지다', '-되다', 이중 피동
- 하라: 행위자를 세우고 단호한 능동 동사로 끝낸다
- 근거: 수동
- 예: 착각이 되어집니다 → 착각해버립니다

## R4 끝에 힘 싣기 [채택]
- 언제: 핵심 정보가 문장 앞이나 가운데 묻힐 때
- 하라: 가장 힘 있는 말을 서술어 자리로 뺀다
- 근거: 수동
- 예: 3초 만에 눈길을 사로잡는 것이 제일 중요합니다 → 제일 중요한 것, 그건 3초 만에 눈길을 사로잡는 겁니다

## R5 호흡 교차 [채택]
- 언제: 비슷한 길이의 문장이 세 번 이상 이어질 때
- 하라: 단문으로 치고, 중문으로 깊이를 주고, 단문으로 쐐기를 박는다
- 근거: 수동

## R6 변명조 부정문 금지 [채택]
- 언제: '~가 아니다. ~였다' 식으로 해명할 때
- 하라: 일어난 일을 단호한 긍정문으로 바로 던진다
- 근거: 수동
- 예: 운이 나빠서가 아니다. 현실에서 눈을 돌린 대가였다 → 폰에 코를 박고 걸은 멍청한 대가였다

## R7 세로 스크롤 여백 [채택]
- 언제: 모바일 연재 본문
- 하라: 문장을 잘게 쪼개고 줄바꿈을 타격 지점으로 쓴다
- 근거: 수동

## R8 콜드 오프닝 [채택]
- 언제: 회차·장면의 시작
- 하라: 상황 설명 대신 감각(후각·촉각·통각)이 있는 장면으로 바로 던진다
- 근거: 수동

## R9 보상에는 인과 [채택]
- 언제: 기연·시스템 보상이 주어질 때
- 하라: 실수 → 재난 → 처절한 생존 의지가 보상을 끌어내게 한다. 우연은 쓰지 않는다
- 근거: 수동
